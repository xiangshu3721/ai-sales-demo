# 销智通·AI销售系统（演示版）

> 纯前端、假数据的「AI 销售系统」演示站。**所有人名、公司名、客户名、数字均为虚构**，不接真实企业微信 / AI / 后端，不收集任何数据，无密钥。

- 在线体验：<https://xiangshu3721.github.io/ai-sales-demo/>
- 技术：原生 HTML / CSS / JS，无构建、无外部 CDN、系统字体；hash 路由；雷达图为 SVG 自绘。
- 本地运行：`python3 -m http.server 8000` 后打开 <http://localhost:8000/>（直接双击 `index.html` 也可）。

## 六个页面（hash 路由）

| 路由 | 页面 | 内容 |
|---|---|---|
| `#/workbench` | 1 销售 AI 工作台 | 顶部状态条（新好友 / 通道 / 判断口径）、知识库标签；三栏：会话列表（8 位客户）+ 聊天（含「30 天对比」嵌入组件、AI 托管开关、可发消息触发 AI 自动回复）+ 右侧销售进度 6 步 / 需求解读 / 十维度判断（待确认项可点击确认）/ 案例匹配（可点「发」把案例发到聊天）；底部「自动通过 + 十维度判断」流程卡与「把这个高意向客户交给销售专家 →」交接单弹层 |
| `#/cases` | 2 案例库后台 | 深色侧栏 + 浅灰内容区；程序生成 **3374 条**案例；昵称 / 案例内容（回车成关键词）/ 标签多选 / 产品多选 / 搜索 / 清空；10·20·40 条分页 + 跳页；精华/新增标、增长徽标；查看 / 驳回(可撤销) / 复制；「选策略精推卡片」智能推荐（按客户十维判断排序）；AI 处理日志定时逐行滚出；底部「这通怎么打 → 生成这通的打法」 |
| `#/playbook` | 3 这通怎么打（打法卡） | 点生成有约 3 秒「生成中」动画，按所选客户 + 案例拼装四步（开场第一句 / 本通重点挖 / 讲哪个案例 / 三个高频问题，可「展开算法」）+ 目标 + 「每句话从哪来」溯源面板 + 备课用时对比 + 复制文字 + 「交给通话分析 AI 员工 →」 |
| `#/review` | 4 通话复盘 | 4 通电话可切换；左：逐字稿（九步分段、销售红字 / 客户黑字、关键词高亮、改进标记）；右：总分、红字点评、2×2 洞察、顾问式成交九步 3×3（点格子看「标准 vs 实际」）；「把这通的短板交给高意向跟进 →」 |
| `#/profile` | 5 个人明细 | 3 位顾问人卡切换；本周总分 / 通话 / 约访率 / 成交 / 趋势；通话表（点行看六维小分，同时在雷达图叠加该通）；SVG 六维雷达（本人实线 / 团队最好虚线 / 团队均值点线）；规律列表（带口径编号）；「确认今日源单与阻碍，把本周成交数据交给 SOP 迭代 →」 |
| `#/practice` | 6 陪练 | 陪练安排表（5 人，状态随演练更新）+ 每日目标；苏晴今日第 2 轮：3 道题，每题 A/B/C + **真实 8 秒倒计时**，超时自动应答；实时评分与六维动作分条动画、即时批注；练后报告；「…交给 SOP 迭代 →」 |

## 跨页联动

1. 工作台 → 交接单（选接收人 / 通话时间）→ **案例库**（带客户上下文，自动智能推荐并选中最相似案例）
2. 案例库 选案例 → 「生成这通的打法」→ **打法卡**（用该案例 + 客户拼装）
3. 打法卡 → 「交给通话分析 AI 员工」→ **通话复盘**（顶部带「已载入打法卡」对照，自动选中该客户对应通话）
4. 复盘 → 「短板交给高意向跟进」（勾选短板）→ **个人明细**（带入短板与二次跟进标记，可跳陪练）
5. 个人明细 / 陪练 → 「交给 SOP 迭代」→ 弹层：确认源单与阻碍（按复盘短板预勾）→ 迭代动画 → 结果 SOP v3.2 → v3.3 → 去陪练验证 / 回工作台

## 假数据说明

- `js/data.js`：8 位客户（含聊天记录、十维判断、案例匹配）、案例生成器（固定随机种子，3374 条，另有 7 条手工校准的关键案例如 C31/C08/C52/C27/C26/C44/C19）、4 通通话转写与九步得分、3 位顾问的本周明细、陪练题目与评分规则、SOP 迭代结果。
- 所有名字（林老师、吴老师、苏晴、陈默……）、「销智通」品牌、数字均为虚构，与任何真实人物 / 公司无关。页面角落有「演示数据均为虚构」。
- 状态仅保存在当前标签页的 `sessionStorage`（跨页上下文），不上传任何内容。

## 文件结构

```
index.html            外壳 + 路由容器
css/base.css          全局样式（顶栏、抽屉、按钮、弹层）
css/pages.css         六个页面样式 + 响应式（≤1180 / 900 / 560 / 420）
js/util.js            工具、弹层、hash 解析、会话状态
js/data.js            全部假数据与生成器
js/sop.js             SOP 迭代弹层
js/pages-*.js         六个页面
js/app.js             路由 / 导航 / 抽屉
```

## 移动端

≤900px：顶栏变汉堡 + 抽屉；工作台三栏变「会话 / 聊天 / 判断」分段切换；案例库侧栏变抽屉、卡片 2 列（≤560 单列）、AI 日志变可折叠条；复盘分「得分与短板 / 逐字稿」；表格转卡片；主要按钮 ≥ 44px；无横向溢出（已在 320 / 390 / 768 / 1024 / 1440 验证）。
